Hardware Connection Topology

  • 1 Hardware Connections: Connect R307 / AS608 Fingerprint Module to Raspberry Pi GPIO Header:
    • VCC ➔ Raspberry Pi 5V (Pin 2)
    • GND ➔ Raspberry Pi GND (Pin 6)
    • TX ➔ Raspberry Pi RXD GPIO15 (Pin 10)
    • RX ➔ Raspberry Pi TXD GPIO14 (Pin 8)
  • 2 Raspberry Pi Software: Install Python dependencies: 
    pip install pyfingerprint requests socketIO-client
  • 3 Run Python Bridge: Execute the script on your Pi to send live attendance POST events!

raspberry_pi_biometric_scanner.py (Python Source Code for Pi) 
import time
import requests
from pyfingerprint.pyfingerprint import PyFingerprint

SERVER_URL = "http://192.168.1.100:3000/api/biometric-scan"
SENSOR_PORT = "/dev/ttyS0"
BAUD_RATE = 57600

print("[BioPulse Pi] Initializing Raspberry Pi Fingerprint Sensor...")

try:
    f = PyFingerprint(SENSOR_PORT, BAUD_RATE, 0xFFFFFFFF, 0x00000000)
    if not f.verifyPassword():
        raise Exception('Sensor password verification failed!')
    print("[BioPulse Pi] Sensor Online! Enrolled Templates:", f.getTemplateCount())
except Exception as e:
    print('[ERROR] Sensor initialization error:', str(e))
    exit(1)

print("[BioPulse Pi] Ready for Student Scans. Touch finger to scan...")

while True:
    try:
        if f.readImage():
            f.convertImage(0x01)
            result = f.searchTemplate()
            positionNumber = result[0]
            accuracyScore = result[1]

            if positionNumber >= 0:
                print(f"[SUCCESS] Match Found! Finger ID #{positionNumber}")
                payload = {
                    "fingerprint_id": positionNumber,
                    "confidence": accuracyScore,
                    "device_id": "RASPBERRY_PI_NODE_01",
                    "timestamp": time.strftime("%Y-%m-%d %H:%M:%S")
                }
                res = requests.post(SERVER_URL, json=payload, timeout=3)
                time.sleep(2)
            else:
                print("[WARNING] Fingerprint not recognized!")
                time.sleep(1)
    except Exception as scan_err:
        time.sleep(1)
